What is Hackimi?

Hackimi is an open-source coding agent you can run anywhere — your laptop, your own GPU box, or a cloud cluster when you need more. It reads your entire repository into context, plans edits across files, runs tests, and shows you every change as a reviewable diff.

One agent, two frontends: a TUI inside your terminal, and a panel inside your editor. Same session, same plan, same privacy. Read the docs or start with a one-line install above.

Features

Everything between your first tab press and your merge button.

Same agent, both worlds — terminal native, IDE friendly, CI ready.

Infinite context

Indexes your whole repo — the code, the tests, and the 9-month-old decision in the comments.

make clean && hackimi index

Agent from anywhere

Queue work from your editor, CLI, or CI. Local or cloud GPUs — same session, same plan.

hackimi deploy app --gpu 4

Rules that stick

One rules file for the team. The agent inherits your conventions, your CI gates, and your API style.

rules: "no fetch without abort signals"

Time-travel diffs

Every agent edit is a reviewable diff. Approve, reject, or fork the session and keep both branches.

hackimi session ls --recent 30

Private by default

Your code never trains anything, and never leaves your machine unless you deploy it yourself.

--privacy "yours, absolute"

Measured, not marketed

Real benchmarks from real repos, published monthly. Try it on your own codebase first.

hackimi benchmark run .
